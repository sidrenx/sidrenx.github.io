# sidrenx.github.io

Personal portfolio site built with plain HTML, CSS, and JavaScript. No frameworks or build step.

## Files

- index.html — Page structure and content
- style.css — Theme variables, layout, and responsive styles
- script.js — Scroll reveal, reading progress bar, active nav highlight, custom cursor, and copy-email button
- favicon.svg — Vector s. site icon

## Run locally

Open index.html directly or run a local server:

    python3 -m http.server 8000

## Updating content

- Bio & facts: Edit the #about section in index.html.
- Adding projects: Remove .empty-projects in #work and uncomment the .project-grid template in index.html.
- Colors & fonts: Edit the CSS variables at the top of style.css.
